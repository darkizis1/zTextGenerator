# Шрифты из .ttf (без картинок букв)

Теперь для шрифта не нужны картинки букв и сторонние плагины ресурспаков (ItemsAdder / Nexo / Oraxen).

## Как подключить шрифт

1. Закинь файл шрифта в папку плагина:

```
plugins/zTextGenerator/fonts/MyFont.ttf
```

2. Напиши название файла (без расширения) как алфавит в своих текстах:

```yaml
texts:
  - name: "example"
    alphabet: "MyFont"
    lines:
      - "Привет, это мой шрифт!"
```

Всё. Плагин сам:

- читает файл `MyFont.ttf`;
- считает ширину каждой буквы (по этому размеру текст выравнивается по центру/краям);
- рисует буквы в текстуру и собирает ресурспак (`plugins/zTextGenerator/generated/zTextGenerator-TTF.zip`);
- отдаёт этот пак игрокам.

Папка `fonts` создаётся автоматически, внутри лежит `README.txt`.

## Как игроки получают ресурспак

В `config.yml`:

```yaml
ttf:
  resource-pack:
    send-on-join: true      # отправлять пак игроку при входе
    auto-host: true         # плагин сам поднимает http-сервер с паком
    host: "0.0.0.0"
    port: 8163
    public-address: "мой.сервер.ру"   # адрес, по которому игроки видят сервер
    url: ""                 # либо свой прямой линк на zip (тогда auto-host не нужен)
```

Если не хочешь встроенный сервер — впиши свой `url` на zip-файл, либо просто раздай
`generated/zTextGenerator-TTF.zip` вручную (например, вместе с ресурспаком сервера).

## Основные настройки

```yaml
font-type: AUTO   # AUTO = если есть .ttf, используется он; иначе шрифт ItemsAdder/Nexo/Oraxen
ttf:
  enabled: true
  size: 9         # высота букв в пикселях (9 — как обычный текст в инвентарях)
  default-font: "" # шрифт для алфавитов, где не указан ключ font
```

В своих `alphabets/*.yml` можно указать конкретный файл шрифта:

```yaml
name: "normal"
font: "MyFont"    # необязательно; без этого ключа берётся default-font
```

Строки `font-infos` (ширины букв) при использовании ttf игнорируются — они берутся из файла шрифта.
Старые алфавиты (`normal`, `tiny`) продолжают работать, только буквы рисуются ttf-шрифтом.

## Ограничения

- Название инвентаря-фона (`inventory-name`, например `generic_dark_full`) в режиме TTF игнорируется —
  картинка фона берётся только из ресурспака, поэтому её там должен предоставить твой пак.
- Поддерживаются символы: ASCII, латиница, кириллица и часть символов (€, №, ₽, °, «», — и т.д.).
  Если буквы нет в ttf-файле, она рисуется ванильным шрифтом.
